1. البداية للمحادثة الجديدة

اقرأ هذا الملف أولًا، ثم اقرأ فقط الكود أو الأدلة اللازمة للطلب الجديد. لا تقرأ التاريخ الكامل أو المجلدات المولّدة أو أوزان النماذج. اتبع تعليمات المستخدم وAGENTS الحالية، ولا تعتبر هذا الملف ضمانًا بأن الخادم ما زال يعمل أو الاختبارات أُعيدت الآن.

2. الهدف والقرارات المعتمدة

  1. تحرير/توليد الصورة: FLUX، مع أدوات تهيئة ومحرر وإزالة خلفية اختيارية.
  2. مراجعة واعتماد صريح: نفس الصورة المعروضة، دون نموذج أو فلتر وسيط.
  3. مسار القلم: استخراج، اختيار واستبعاد، تدقيق، محاكاة وتصدير SVG وJSON.

العمل للموقع على الحاسوب؛ الهاتف مؤجل. لا اختيار ذراع فعلي ولا معايرة مادية حتى الآن. لا تغيّر سياسة زمن الرسم أو السرعات الافتراضية ولا تضف سقف وقت رسم دون طلب؛ المستخدم أجّل هذا القرار.

المستخدم يريد الحفاظ على الأصل والألوان. لا تحول إلى الرمادي أو تنظف التفاصيل تلقائيًا. التحويلات الفنية من FLUX نفسه، وليس فلاتر OpenCV تُقدَّم باعتبارها خرج النموذج.

4. التشغيل والفحص

من جذر المشروع؛ يطلق خدمة خلفية مخفية أو يتحقق من الخدمة الموجودة، ولا يضيف تشغيلًا تلقائيًا عند إقلاع Windows:

.\flux-studio\start-server.ps1
Start-Process http://127.0.0.1:8770/prepare

عند تغيير كود الخادم، تحقق من عدم وجود معالجة قبل إعادة تشغيل عملية هذا الخادم تحديدًا. مؤشر القفل: GET /api/generation?summary=1 → processing. سجلات الخادم flux-studio/server-stdout.log وserver-stderr.log. لا تطبع صور data URLs أو الأسرار.

المتصفح يُفحص عبر cua_repl. اختيار الملفات لم يعمل باستمرار في أداة المتصفح؛ نجح لصق PNG عبر Clipboard API ثم Ctrl+V. لا تحقن حالة التطبيق أو DOM لتنفيذ اختبارات وهمية.

6. السلوك الذي يجب الحفاظ عليه

  • اختيار طريقة الخلفية يطبقها مباشرة حتى إذا كان «التحديث المباشر» مغلقًا. بقية الإعدادات تتبعه أو زر التطبيق.
  • التهيئة الافتراضية style=color وdenoise=0 وcontrast100 وbrightness0. إزالة الخلفية وحدها تحفظ RGB؛ الرمادي خيار صريح.
  • Alpha محفوظ عبر فلاتر المحرر والهندسة وPNG، وأوضاع القلم تتجاهل RGB المخفي خلفه.
  • الأدوات تُقفل أثناء الطلب؛ الأخطاء ظاهرة ولا تختفي مع شريط المعالجة. لا نسب تقدم مصطنعة.
  • قياس الخطة الكاملة لا يُعاد استعماله لخطة ذات خطوط مستبعدة أو قصيرة محذوفة.
  • 11 مقاس ورق قياسيًا ومخصص؛ الاتجاه وحجم الرسم والهوامش تشمل كامل أثر القلم. تغيير الهندسة يعيد بناء المسارات ويلغي الاستبعادات مع تنبيه موضح بالواجهة.
  • SVG بوحدات mm ومسارات فقط، وJSON يحمل simulationOnly=true. الأصل على القرص لا يُستبدل؛ قد تصغر نسخة العمل عند الاستيراد إلى2000px و4ملايين بكسل.
