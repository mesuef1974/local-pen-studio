# حافّة — مختبر حواف OpenCV

صفحة مستقلة عن تطبيق الرسم. المدخل صورة، والمعالجة عبر Python وOpenCV، والمخرج صورة حواف PNG. لا توجد نماذج أو أوزان أو خدمات سحابية.

## التشغيل

```powershell
python edge-studio/launch.py
```

الرابط: http://127.0.0.1:8766/ . للتشغيل دون فتح المتصفح: `python edge-studio/server.py`.

## الاعتماديات

Python 3.12 مع `opencv-contrib-python` و`numpy` و`Pillow`. استخدم بيئة واحدة لـ OpenCV؛ لا تثبّت حزم OpenCV المتنافسة معًا. المكتبات موجودة مسبقًا على الجهاز الحالي، ولم تُثبّت تبعيات جديدة لهذا العمل.

## الأدوات

- Canny: العتبتان، عتبات من وسيط الصورة، هامش العتبات، فتحة المشتقة، L2.
- EdgeDrawing: التدرج، الارتكاز، فاصل المسح، طول المقطع، سيغما، مؤثر المشتقة، PF، جمع التدرجات.
- Sobel، Scharr، Laplacian، والتدرج المورفولوجي: الاتجاه والحجم والعتبة والتطبيع بحسب الطريقة.
- تجهيز الصورة: الدقة، القنوات، السطوع، التباين، غاما، موازنة المدرج التكراري وCLAHE.
- الضوضاء: Gaussian، Bilateral، Median وNon-local means.
- التنقية: إغلاق، فتح، حذف المكونات الصغيرة، ترقيق، سماكة نهائية.
- PNG بلون قابل للتغيير وخلفية بيضاء أو سوداء أو شفافة، وتصدير/استيراد إعدادات JSON.
- مقارنة الأصل أو المدخل المجهز، عرض الحواف منفردة، تراكب، تكبير وتحديث مباشر.
- 52 تفضيلًا خاصًا بالخوارزميات الست: 8 لكل طريقة، و10 لكل من Sobel وScharr مع الاتجاهات الأفقية والرأسية. يضبط التفضيل التجهيز والكشف والتنقية معًا دون تغيير الطريقة المختارة أو الدقة واللون والخلفية. التعديل اليدوي لإعداد المعالجة يحوّل الحالة إلى «مخصص».

المفاتيح الخاصة بالخطوط والدوائر والتعرف والتعقب في OpenCV ليست أدوات كشف حواف، ولم تُضف. إعدادات الخوارزميات والتجهيز المعروضة مرتبطة بالمعالجة فعلًا، ويُخفى غير المناسب للطريقة المحددة.

## الدقة والخصوصية

يُفتح الملف محليًا في المتصفح، ثم يُصغّر إلى أقصى ضلع 2000 بكسل قبل إرساله لسيرفر الجهاز. المعالجة لا تكبّر المصدر ولا تعيد تفاصيل غير موجودة. حد المدخل الداخلي أربعة ملايين بكسل؛ الاستيراد يقبل PNG/JPG/WebP حتى 20 ميغابايت. الملفات الشفافة تُركب على الأبيض قبل الكشف، وشفافية PNG النهائي مستقلة عن ذلك.

النتيجة المعروضة تصبح سابقة عند تغيير الإعدادات، ويُعطّل حفظها حتى اكتمال آخر طلب. الشريط الأزرق غير محدد النسبة: يعبّر عن طلب فعلي قيد التنفيذ ولا يدعي معرفة الوقت المتبقي. زمن المعالجة المقاس يخص تجهيز الحواف وترميز الصور على السيرفر ولا يشمل نقل الطلب أو فك الصورة في المتصفح.

الصورة التجريبية نسخة من الصورة المرجعية المستخدمة محليًا في المشروع السابق. لا تُكتب الصور المرفوعة إلى القرص. الخلفية الشفافة محفوظة فعلًا في قناة alpha عند التصدير، ولو ظهرت مربعات الشفافية في المعاينة.

## التحقق

من مجلد `edge-studio`:

```powershell
python -m unittest test_processing -v
node --check app.js
node test-workflow.cjs
node test-presets.cjs
python -m unittest test_presets -v
```

هذه خوارزميات حواف تقليدية؛ قد تلتقط الظل والملمس، ولا تفهم هوية الوجه أو أهمية الملامح. الإغلاق والتثخين يضيفان حبرًا، والفتح وحذف المكونات قد يزيلان تفاصيل صحيحة.

المراجع: [Canny والمشتقات](https://docs.opencv.org/4.10.0/dd/d1a/group__imgproc__feature.html)، [إعدادات EdgeDrawing](https://docs.opencv.org/4.10.0/d0/da6/structcv_1_1ximgproc_1_1EdgeDrawing_1_1Params.html).
