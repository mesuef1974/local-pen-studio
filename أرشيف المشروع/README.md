# أرشيف المشروع

هذا المجلد يجمع تقارير مرجعية ومخرجاتها وملفات التسليم التي كانت مبعثرة في جذر المستودع. لا يمثل محتواه بالضرورة الحالة الحالية للتطبيق؛ راجع تاريخ كل تقرير ونطاقه قبل الاعتماد عليه.

## المحتويات

### تقارير الذكاء الاصطناعي المحلي

في [تقارير الذكاء الاصطناعي المحلي](تقارير%20الذكاء%20الاصطناعي%20المحلي/) يوجد تقرير HTML، ودليل النماذج المرتبط به، وملفات الأدلة، ومولّدا التقريرين. تبقى الروابط بين التقرير ودليل النماذج وملفات JSON في المجلد نفسه حتى تعمل دون تعديل.

لإعادة بناء التقارير استخدم من هذا المجلد:

```powershell
python build_local_ai_report.py
python build_models_guide.py
```

### التسليمات

يحفظ مجلد [التسليمات](تسليمات/) لقطات التسليم التاريخية. راجع التاريخ والحالة قبل استخدامها بوصفها تعليمات تشغيل حالية.

## سياسة الحفظ

- ملفات HTML وJSON والصور المرجعية تتبع Git عند السماح بها في `.gitignore`.
- ملف `local-ai-report-print-check.pdf` يبقى أرشيفًا محليًا مستبعدًا من Git، حفاظًا على سياسة ملفات المعاينة المطبوعة.
- لا تحفظ هنا سجلات جلسات Codex أو الأوزان أو الأسرار أو بيئات التشغيل.
- التقارير الحية وخطط التنفيذ الحالية تبقى في `docs/`، وتقارير التنسيق في `docs/coordination/`.
