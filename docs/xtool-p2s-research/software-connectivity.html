حالة API والتكامل البرمجي

لا يوجد في المراجع الرسمية التي فُحصت API عامة موثقة للمطورين. المسارات المثبتة للمستخدم هي xTool Studio وميزات LightBurn بحسب الإصدارات المتوافقة. لا نعامل عنوان IP أو خيار اتصال شبكي كواجهة API مستقرة.

يوجد مشروع مجتمعي يدرس بروتوكول P2S عكسيًا، ويصف REST/WSS بحسب وثائقه. هذا تحليل طرف ثالث يتغير وقد يحمل مخاطر تشغيلية؛ لم نختبره على جهاز المالك ولا نعتمده كواجهة إنتاج.

لم يتم الاتصال بالطابعة أو تثبيت أي برنامج. هذه صفحة توثيقية فقط. لا تتضمن الشيفرة أوامر تشغيل أو تحكم، ولا ترسل معلومات إلى الخارج.

ما يلزم قبل بناء تكامل خاص بالتطبيق

  • تثبيت إصدار xTool Studio وLightBurn والبرنامج الثابت على الجهاز الفعلي.
  • توثيق نظام التشغيل وطريقة الربط المسموح بها (USB أو شبكة) في بيئة المالك.
  • طلب وثيقة SDK/API رسمية من الشركة؛ عند غيابها، إجراء مراجعة سلامة وقانونية مستقلة لأي تحليل بروتوكول.
  • اختبار قراءة الحالة دون إطلاق مهمة، ثم عزل أي اختبار حركة/ليزر في بيئة آمنة وبإذن وإشراف.
  • تحديد حدود الفشل والإيقاف وتسجيل موافقة المستخدم قبل الانتقال من التصدير إلى الاتصال المباشر.
معلومات البرنامج والبرنامج الثابت سريعة التغير؛ تحقق من المصادر الرسمية قبل التحديث. العودة إلى النظرة العامة.
