# بحث xTool P2S

مجلد مرجعي للطابعة الموجودة: xTool P2S CO₂ بقدرة 55W.

- `index.html`: بوابة RTL لمحتويات الملف وروابط وثائق الشركة.
- `user-experiences-ar.html`: تجميع وتحليل التجارب والمراجعات المنشورة مع الروابط الأصلية. المحتوى تلخيص تحريري وليس اقتباسًا حرفيًا.
- `xTool-P2S-Quick-Start-Guide-EN.pdf`: دليل البدء السريع الرسمي بالإنجليزية، محفوظ محليًا من xTool Support.

راجِع دليل الشركة وملصق جهازكم قبل التشغيل؛ تتغير المعلومات حسب إصدار الجهاز والبرمجيات والملحقات. تجارب المستخدمين أدلة فردية وليست إحصاء أعطال أو ضمان أداء.
# تحديث الجولة الثانية — 28 أكتوبر 2026

أضيفت مكتبة فيديو محلية `video-library-ar.html` تضم روابط مشاهدة لمواد xTool الرسمية ومراجعات واختبارات مستقلة. أضيفت روابط مركز دعم P2 Series، وإرشادات تدريب مسؤول السلامة، ودليل الفك والتشغيل في الأجواء الحارة، وصفحات أعطال USB والكاميرا ومضخة الهواء والمروحة والناقل والقياس التلقائي.

وُسّع `user-experiences-ar.html` بحالات إضافية منها اختبارات فيديو مفصلة، وتجارب اتصال Wi-Fi، وانطباع إيجابي، وبلاغ ضعف القطع، وشكوى دعم. جميعها مميزة كتجارب فردية لا كإحصاءات.

لا يتضمن تنزيل ملفات الفيديو، لأن الفيديوهات مملوكة لـ xTool أو منشئيها وتُشاهد من صفحاتهم الأصلية؛ الروابط المباشرة محفوظة في مكتبة الفيديو. المحفوظ محليًا حتى الآن هو دليل البدء السريع الرسمي بالإنجليزية. لم أجد في صفحة الدليل الرسمية نسخة عربية؛ تعرض الصفحة عدة لغات أخرى وروابطها.
