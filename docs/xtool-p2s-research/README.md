# بوابة xTool P2S

مرجع محلي ساكن للوثائق والمراجع العامة الخاصة بطابعة xTool P2S. واجهة القراءة العربية موجودة في `index.html` وجميع الصفحات في هذا المجلد.

## التشغيل

يتطلب Python 3 فقط ولا يثبت حزمًا. شغّل الأمر من جذر المستودع كي يستطيع الخادم تقديم ملف الهوية المركزي الموجود في `docs/coordination/assets/identity.css`:

```powershell
python -m http.server 8786 --bind 127.0.0.1
```

ثم افتح `http://127.0.0.1:8786/docs/xtool-p2s-research/`. هذا المسار مهم: تشغيل الخادم من مجلد البوابة وحده يمنع تحميل ملف الهوية المركزي الموجود خارجه. للإيقاف اضغط `Ctrl+C` في نافذة الخادم. الخادم مربوط بعنوان loopback فقط.

## خريطة الصفحات

- `index.html` — نظرة عامة وخريطة البوابة.
- `setup-safety.html` — الإعداد والتشغيل والصيانة والسلامة.
- `materials.html` — المواد والعمليات والتحذيرات والتعارضات.
- `software-connectivity.html` — الصيغ والاتصال وxTool Studio وLightBurn وحدود API.
- `user-experiences-ar.html` — تجارب ومراجعات منفردة من مصادرها.
- `visual-guides.html` — صور فوتوغرافية منسوبة، وصورة منتج رسمية، ورسومات SVG أصلية توضيحية.
- `video-library-ar.html` — جدول بيانات وصفية وروابط أصلية فقط؛ لا فيديو مستضاف أو منسوخ.
- `references.html` — مصادر خارجية وروابط الملفات المحلية.
- `source-inventory-ar.html` — مواقع وبصمات الملفات الموجودة قبل التحرير وقرار إعادة الاستخدام.
- `xTool-P2S-Quick-Start-Guide-EN.pdf` — دليل بدء سريع رسمي بالإنجليزية، محفوظ دون تعديل.
- `../coordination/assets/identity.css` — الهوية المركزية والخطوط المحلية المشتركة؛ و`assets/portal.css` تخطيط البوابة ومكوّناتها باستخدام رموز الهوية، و`assets/portal.js` للتنقل والتعامل مع صور المراجعة المحلية الاختيارية. لا مكتبات أو خطوط خارجية.
- `assets/p2s-official-product-render.jpg` — صورة المنتج الرسمية من غلاف الدليل المحفوظ.
- صور Gadgeteer الفوتوغرافية اختيارية ومحلية فقط، مستثناة من Git عبر `.git/info/exclude` بسبب غياب ترخيص إعادة نشر صريح؛ تعرض البوابة روابط المصدر عند عدم توافر الصور.
- `verify_portal.py` — مدقق محلي دون اعتماديات لهيكل HTML وRTL والروابط النسبية وشروط فهرس الفيديو.

## التحقق الآلي

من جذر المستودع نفّذ `python docs/xtool-p2s-research/verify_portal.py`. يعيد المدقق فحص الصفحات التسع وروابطها المحلية وبنية جدول الفيديو، ويخرج رمز فشل عند وجود مشكلة.

## الخصوصية والحدود

لا تستخدم الصفحات طلبات شبكة خارجية تلقائيًا أو أدوات تتبع. الروابط الخارجية تنفتح فقط عندما يختارها القارئ. الموقع لا يتصل بالطابعة ولا ينفذ أوامر تشغيل أو شراء. المحتوى الخارجي تم الاطلاع عليه في 29 أكتوبر 2026؛ تحقق من النسخة الحالية ومن ملصق جهازك ودليله قبل التطبيق.

تجارب المستخدمين أمثلة نوعية وليست إحصاءات. معلومات التوافق لا تضمن جودة النتيجة أو سلامة مادة. عند التعارض، تقدم تحذيرات السلامة ودليل النسخة الفعلية على أي قائمة عامة.
