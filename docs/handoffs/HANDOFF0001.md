## الحالة


أُصلح ربط المراقبة التلقائية عبر جسر سجل الجلسة الحقيقية، باسم transcript_bridge.
وضع observe وعتبة 200 ألف باقيان، ولا إنشاء أو نقل ملكية أو أرشفة أو نشر. الخطافات
الأصلية ما زالت موثوقة، لكن لا نزعم أن التطبيق بدأ إرسالها.

## الهدف والتفويض

تفويض المستخدم: تنفيذ السكربت والخطافات واختبارها أولًا دون نقل الجلسة الحالية أو
أرشفتها. أي تفعيل للانتقال الحقيقي يحتاج تفويضًا لاحقًا وتجربة ربط منفصلة.

## المنجز وأدلة التحقق


المراقب الأساسي له 34 اختبارًا، ولجسر Work ثلاثة عشر اختبارًا؛ نجحت 47 حالة مختلفة
محليًا. يغطي الفحص الملكية والكتابة الذرية والقياس والبدء/الانتهاء الجزئي للأدوات
والملفات المقتطعة وحفظ المؤشر والعمل المنفصل. أُضيف الجسر إلى CI على Windows وLinux.
نجح اختبار فعلي دون حقن JSON يدوي: عملية مخفية مستقلة التقطت task_started وأحداث
الأدوات من سجل الجلسة الحالية؛ سجلها أظهر UserPromptSubmit وPreToolUse وPostToolUse
مع owner_match=true وtransport=transcript_bridge، وحدثت العدادات بعد أوامر قراءة عادية.
حفظت هوية المالك نفسها، وبقيت الأداة الجارية نشطة. النتائج والنبض والمؤشر المحلي
في مجلد bridge داخل بيانات Git، وليست نصوص المحادثة أو الأوامر.

## الخطوة الجارية



الجسر يعمل تلقائيًا في الخلفية لهذه الجلسة دون تشغيل عند إقلاع Windows. السبب في
تكاملنا كان انتظار خطافات CLI المحلية دون ربط بمصدر الأحداث الذي تسجله جلسة Work
الحالية. أُصلح ذلك بجسر واضح المصدر؛ لا نعده تعديلًا لنواة Codex أو إثباتًا أن
الخطافات الأصلية أصبحت تصدر من التطبيق. يوجد فصل صريح بين النقلين في أثر الدخول.

## الخطوة التالية



انتظر المستخدم. عند الدور التالي تحقق من أن الجسر رصد Stop للدور السابق وبدء الدور
الجديد؛ لا يمكن ادعاء رصد نهاية الرد قبل إرسالها. لا تنقل الجلسة أو تؤرشفها ولا
تفعّل موصلًا حيًا. عند توقف العملية بعد إعادة تشغيل الجهاز استخدم أمر start الموثق؛
لا تفترض وجود مهمة بدء تشغيل. تحقق من حالة فحوص GitHub لفرع fix/handoff-work-event-bridge
أو الطلب المرتبط قبل أي دمج أو نشر.

## المعلق غير المتحقق


حقن السياق ومنع أدوات قبل التنفيذ والمتابعة الآلية ليست مدعومة في جسر السجل؛ هو
مراقب بأحداث لاحقة ويظل النقل الحقيقي معطلًا. أحداث Subagent غير المحسومة والعمل
المنفصل تمنع الجاهزية بدل افتراض انتهائها. صيغة سجل Codex قد تتغير؛ الفشل أو
الدور غير المعروف أو ملف مقتطع/مستبدل يوقف الجسر ويمنع الجاهزية. لم يختبر Stop
للدور الجاري حيًا قبل انتهاء الرد. تنبيهات التبعيات السابقة على GitHub لم تعالج
ضمن هذه المهمة وتحتاج مراجعة قبل النشر.

## العمليات المعلقة


توجد عملية مراقبة محلية فقط، يحدد PID الحالي ملف bridge/status.json؛ لا تعتمد رقمًا
قديمًا من نص البطاقة. لم يبدأ هذا التنفيذ توليد صور أو نشرًا. فحوص GitHub مرجعها
طلب الدمج الحالي. يجب فحص معالجة المنصة وGit والعمليات غير المحسومة قبل أي نقل
مستقبلي، ولا يعني المراقب ضمان خمول جميع برامج الجهاز.
