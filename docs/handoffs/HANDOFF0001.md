## الحالة

أُلغي التمرير الداخلي للوحة أدوات `flux-studio` وأصبحت الأدوات جزءًا من تمرير
الصفحة الوحيد على سطح المكتب والعرض الضيق. أُرشفت الجلسة الثانية بطلب المستخدم،
وأُلغي ترشيحها، ومهمة الانتقال التلقائي متوقفة مؤقتًا. لا أرشفة تلقائية ولا نشر.

## الهدف والتفويض

تفويض المستخدم الحالي: إزالة تمرير لوحة الأدوات المزدوج مع إبقاء تمرير الصفحة
الوحيد. لا تغيير في سير الصور أو النماذج أو النشر أو التبعيات.

## المنجز وأدلة التحقق

أزيل `overflow-y:auto` وحد الارتفاع المرتبط بالنافذة وتثبيت لوحة الأدوات وتبويباتها،
وأزيل حد `70dvh` من العرض الضيق. بقي تمرير معاينة الصور وحقول النص المستقلة كما هو.
نجحت 29 حالة JavaScript، وفحص CSS المخصص و`git diff --check`. أكد الفحص البصري أن
التمرير من داخل الأدوات يحرك الصفحة كلها، ولم تظهر أخطاء أو تحذيرات في المتصفح.

## الخطوة الجارية

اكتمل تعديل التمرير والتحقق المرتبط به. لا عمل برمجي جارٍ.

## الخطوة التالية

انتظر تعليمات المستخدم الجديدة. لا تعِد تفعيل منسق الانتقال إلا بطلب صريح.

## المعلق غير المتحقق

لم يُفحص كل محتوى الأدوات بعد تحميل صورة أو على هاتف فعلي؛ التحقق شمل الحالة
الافتتاحية على سطح المكتب وقواعد العرض الضيق. تنبيهات التبعيات السابقة على GitHub
خارج نطاق هذا التعديل وتحتاج مراجعة قبل النشر.

## العمليات المعلقة

لا عمليات تطبيق أو توليد أو نشر معلقة. مهمة الانتقال معطلة عمدًا، ولا يوجد مستقبل
مرشح أو نقل معلق. لا يُدعى خمول كل برامج الجهاز.

## مراجع القواعد

القواعد الدائمة: CONTRIBUTING.md وSECURITY.md وdocs/RELEASING.md. لا نشر أو دفع أو دمج
أو إيداع شامل أو تراجع عن تعديلات المستخدم بسبب عتبة السياق. لقواعد المراقب راجع
docs/HANDOFF-AUTOMATION.md. بيانات Git الآلية في مجلد handoff داخل بيانات Git المحلية،
وليست رأسًا متتبّعًا يتسبب في إعادة تعديل البطاقة.
