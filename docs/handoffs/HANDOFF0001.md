## الحالة

بدأ إصلاح جذري لأن المراقب السابق لم يكن يملك موصل إنشاء، وتوقف جسر المسار الثابت،
فلم ينفذ الانتقال عند 200000. العمل الآن على فرع `fix/automatic-handoff-200k`؛
لا إنشاء حي أو نقل ملكية أو أرشفة أو نشر حدث أثناء التطوير.

## الهدف والتفويض

تفويض المستخدم الحالي: حل جذري ينشئ جلسة جديدة تلقائيًا عند 200000 بعد شروط
الانتقال الآمن. تبدأ التهيئة عند 180000. الأرشفة تبقى معطلة حتى يأمر المستخدم
صراحة، ولا نشر أو تجاوز حماية main أو تثبيت تبعيات.

## المنجز وأدلة التحقق

أضيف منسق create-only يستخدم `codex queue` لتجهيز البطاقة و`codex exec` لإنشاء
مستقبل قراءة فقط وإقرار منظم. يمنع إعادة الإنشاء عند نتيجة مجهولة، ويعيد التحقق
من Git والبطاقة قبل نقل الملكية، ولا يؤرشف المصدر. يعيد اكتشاف سجل المالك بدل
المسار الثابت، ويصالح أعلام الأدوات فقط بعد مطابقة السجل واكتمال آخر دور؛ لا يصالح
الوكلاء تلقائيًا. نجحت 63 حالة محلية: 34 للمراقب و15 للجسر و14 للمنسق، إضافة إلى
سياسة المستودع وأربعة اختبارات لها. اختُبرت قناة `codex exec` بجلسة مؤقتة غير
محفوظة وقراءة فقط، وأعادت `thread.started` والرد المتوقع؛ لم تُنشأ جلسة دائمة.

## الخطوة الجارية

مراجعة فرق المنسق واختبار التشغيل الجاف على الحالة الحقيقية. آخر قياس جاف كان دون
العتبة ولم ينشئ جلسة. بعد ذلك يُرفع طلب دمج ويمر عبر الفحوص وحماية main، ثم تُثبت
مهمة Windows ذات الدقيقة الواحدة من النسخة المدمجة. لا نشر أو مزامنة فروع النشر.

## الخطوة التالية

شغّل مجموعة الاختبارات المركزة وسياسة المستودع، ثم راجع الفرق الأمني وأنشئ طلب
دمج للفرع الحالي. لا تثبت المهمة المجدولة قبل دمج الشفرة، ولا تنشئ مستقبلًا حيًا
أثناء الاختبار الحالي.

## المعلق غير المتحقق

لم يُختبر إنشاء مستقبل محفوظ ونقل ملكيته حيًا بعد؛ اختبارات العقد تستخدم خلفية
مزيفة، واختبار CLI كان مؤقتًا. مهمة Windows لم تثبت بعد، والفرع لم يمر عبر CI.
صيغة سجل Codex وJSONL ليست واجهة ثابتة؛
الفشل يحجب النقل. الوكلاء غير المحسومين لا تصالحهم الآلية. تنبيهات التبعيات السابقة
على GitHub لم تعالج ضمن هذه المهمة وتحتاج مراجعة قبل النشر.

## العمليات المعلقة

فرع التطوير وطلب الدمج والتثبيت المجدول ما زالت معلقة كما في بيانات البطاقة.
الجسر القديم متوقف، والمنسق المستمر غير مثبت. المالك المسجل بقي الجلسة المصدر؛
لم تُنقل الملكية ولم تُؤرشف جلسة. لا يُدعى خمول كل برامج الجهاز.

## مراجع القواعد

القواعد الدائمة: CONTRIBUTING.md وSECURITY.md وdocs/RELEASING.md. لا نشر أو دفع أو دمج
أو إيداع شامل أو تراجع عن تعديلات المستخدم بسبب عتبة السياق. لقواعد المراقب راجع
docs/HANDOFF-AUTOMATION.md. بيانات Git الآلية في مجلد handoff داخل بيانات Git المحلية،
وليست رأسًا متتبّعًا يتسبب في إعادة تعديل البطاقة.
