## الحالة

أضيفت أداة دائرة مستقلة إلى محرر الصورة، وتستجيب للحجم والعتامة واللون. أُصلحت
الممحاة لتزيل البكسلات إلى الشفافية الفعلية بدل طلائها بالأبيض. مهمة الانتقال
التلقائي ما زالت متوقفة عمدًا. لا أرشفة تلقائية ولا نشر.

## الهدف والتفويض

تفويض المستخدم الحالي: إضافة دائرة تتأثر بعناصر التحكم والتأكد من عمل الممحاة.
لا تغيير في سير الصور أو النماذج أو النشر أو التبعيات.

## المنجز وأدلة التحقق

أضيفت `circle` باختصار `O` مع قيد نسبة أبعاد 1:1، مع بقاء الشكل البيضاوي مستقلًا.
تستخدم الدائرة عناصر اللون والحجم والعتامة نفسها. تغير دمج طبقة الممحاة إلى
`destination-out` ثم يعيد وضع الدمج الطبيعي. نجحت اختبارات هندسة المحرر و14 اختبار
Python لعمليات الصورة. أكد اختبار فعلي على صورة أن الدائرة تُرسم وأن ممحاة بحجم
80 بكسل تكشف شبكة الشفافية، دون أخطاء أو تحذيرات في المتصفح.

## الخطوة الجارية

اكتمل تعديل الدائرة والممحاة والتحقق المرتبط به. يجري تجهيز التغيير للمراجعة في Git.

## الخطوة التالية

أكمل طلب الدمج والفحوص الآلية ثم انتظر تعليمات المستخدم. لا تعِد تفعيل منسق
الانتقال إلا بطلب صريح.

## المعلق غير المتحقق

لم تُختبر الأداة على هاتف فعلي أو بكل تركيبات اللون والعتامة والحجم؛ اختُبر مسارها
برمجيًا وبصريًا على سطح المكتب. تنبيهات التبعيات السابقة على GitHub خارج نطاق هذا
التعديل وتحتاج مراجعة قبل النشر.

## العمليات المعلقة

لا عمليات تطبيق أو توليد أو نشر معلقة. مهمة الانتقال معطلة عمدًا، ولا يوجد مستقبل
مرشح أو نقل معلق. لا يُدعى خمول كل برامج الجهاز.

## مراجع القواعد

القواعد الدائمة: CONTRIBUTING.md وSECURITY.md وdocs/RELEASING.md. لا نشر أو دفع أو دمج
أو إيداع شامل أو تراجع عن تعديلات المستخدم بسبب عتبة السياق. لقواعد المراقب راجع
docs/HANDOFF-AUTOMATION.md. بيانات Git الآلية في مجلد handoff داخل بيانات Git المحلية،
وليست رأسًا متتبّعًا يتسبب في إعادة تعديل البطاقة.
