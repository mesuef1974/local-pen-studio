# مراقبة استهلاك Codex محليًا

## الحالة التشغيلية

تم التحقق في **28 أكتوبر 2026** من المهمة المجدولة `Codex Usage Logger`: مفعّلة وتعمل كل دقيقة، مخفية، وتمنع تشغيل نسخة مجدولة ثانية بالتزامن. تشير الآن إلى `scripts/usage_monitor/codex_usage_logger.py`. بدأناها يدويًا بعد استقرارها في مجلدها الخاص ضمن المشروع؛ كانت نتيجة المهمة `0`، وتحدّث ملف الحالة، ووجدنا 13 ملف قياس جلسة محليًا. اجتازت اختبارات المسجل الأربعة. تحدّث مسار المهمة مع إبقاء الأداة فعالة.

هذه لقطة تحقق بتاريخها؛ قد تتغير حالة المهمة أو إعدادات الجهاز لاحقًا. حالة `Ready` طبيعية بين مرات التشغيل الدورية ولا تعني أن المهمة متوقفة.

المسجل `scripts/usage_monitor/codex_usage_logger.py` يقرأ أحداث `token_count` وإعدادات النموذج من
سجلات Codex المحلية. لا يرسل رسائل، ولا يستدعي نموذجًا، ولا يقرأ نصوص المحادثة إلى
ملفات القياس. لكل جلسة ملف JSON مستقل في:

`%USERPROFILE%\.codex\usage-logs\sessions`

اسم الملف يجمع الاسم الحالي للجلسة ومعرّفها الثابت. تحتوي كل عينة على النموذج، مستوى
التفكير، حجم السياق، الإجمالي التراكمي، ونسبة الحصة الأسبوعية عندما يوفرها السجل.
المهمة المجدولة `Codex Usage Logger` تشغله محليًا كل دقيقة، ولا تعتمد على خطافات
Codex أو آلية `HANDOFF0001`.

تعرض لوحة HTML المحلية مؤشرات كل الجلسات واتجاهها، وتُحدَّث بياناتها تلقائيًا بعد
كل تشغيل للمسجل. لفتحها وتشغيل خادم محلي على `127.0.0.1:8772` استخدم:

```powershell
.\scripts\usage_monitor\open_dashboard.ps1
```

تعرض اللوحة أربعة خطوط مستقلة لجلسات ليزر وعصف ذهني ومسار القلم وتنسيق إنتاج SVG،
بألوان متباينة ومحور زمني مشترك؛ ويعرض التلميح قيمة كل جلسة عند الساعة المحددة. تعرض رسوم الجلسات ضغط السياق واستخدام الحصة الأسبوعية على محور
النسبة، مع أوقات الذروات وكل عبور مسجل لعتبة 80%. تتحدث الرسوم كل دقيقة مع تحديث ملف
البيانات المحلي. يربط الرصد الحدث بالجلسة والطابع الزمني ونوع الضغط، ولا يخزن نص
الرسالة أو موضعه داخل المحادثة.

أمر محادثة مختصر: «افتح لوحة استهلاك التوكنز المحلية من
`scripts/usage_monitor/dashboard.html` وراجع مؤشرات الجلسات والاتجاه العام.»

لتثبيت المهمة أو تحديثها:

```powershell
.\scripts\usage_monitor\install_codex_usage_logger.ps1
```

للتشغيل اليدوي من جذر المشروع:

```powershell
python .\scripts\usage_monitor\codex_usage_logger.py
```

لتشغيل اختباراته المركزة من PowerShell:

```powershell
Push-Location .\scripts\usage_monitor
python -m unittest test_codex_usage_logger -v
Pop-Location
```

ملفات القياس محلية وغير متتبعة في Git. لا تتضمن النسب الأسبوعية عددًا مطلقًا من
التوكنز المحتسبة على الاشتراك؛ هي لقياس الفرق قبل المهمة وبعدها ومقارنة النماذج.

الإعداد العام في `%USERPROFILE%\.codex\config.toml` هو `GPT-6 Luna / Low` للجلسات
الجديدة. ويوجد ملفا إعداد مختصران للاختيار الصريح من الطرفية:

```powershell
codex --profile luna-low
codex --profile luna-medium
```

الترقية إلى Medium مقصودة للمهام البرمجية المتوسطة عندما لا يكفي Low. اختيار نموذج
يدويًا داخل جلسة مفتوحة يبقى إعدادًا خاصًا بتلك الجلسة إلى أن يغيّره المستخدم.
