# تنسيق الجلسات والتقارير

هذا المجلد هو سجل التنسيق بين جلسات مشروع Local Pen Studio. صفحات التقارير النهائية بصيغة HTML عربية باتجاه RTL، وفهرسها في [index.html](index.html).

## الملكية

- **مالك المشروع وصاحب القرار النهائي:** المستخدم.
- **منسق العصف والتقارير والتوصيات:** جلسة «ليزر» الحالية؛ تجمع الآراء كما صدرت وتكتب التقارير المرتبطة.
- **مسار القلم:** مالك تطوير المسارات وقياساتها.
- **تنسيق إنتاج SVG:** مالك عقد SVG والتحقق والتصدير.

التوصية أو تصويت المشاركين لا يحل محل قرار مالك المشروع. غياب الرد يسجل «لم يرد» ولا يسجل موافقة.

## بنية الموضوع

لكل موضوع مجلد ثابت داخل `topics/`، مثل `TOKEN-SAVING-001/`. يتضمن موجز السؤال، ومحضرًا من كل جلسة، وتقرير تقييم، وملخص توصيات مرتبطًا بمعرّف التقييم، وسجل تصويت عند طلب التصويت، وقرارًا منفصلًا للمالك عند صدوره.

موضوع مراجعة المهارات الحالي هو `topics/SKILLS-REVIEW-001/skills-inventory-ar.html`. الجرد يشمل ما عُثر عليه محليًا فقط؛ آراء الجلسات تصويت استشاري، وأي تغيير في التفعيل أو الأرشفة ينتظر قرار المالك.

## استطلاع رأي الجلسات

عندما يطلب المالك رأي الجميع أو رأي الجلسات المختصة، استخدم سجلًا مركزيًا واحدًا: صف لكل موضوع أو مهارة، وعمود رأي مستقل لكل جلسة مشاركة، وعمود رأي للمنسق عند طلبه، وعمود قرار خاص بالمالك. يُعد رأي كل جلسة صوتًا استشاريًا؛ يسجل «لم يرد» عند غياب الرد ولا يُستنتج التصويت. لا تُنشأ ملفات منفصلة لكل جلسة كطريقة افتراضية. تُدرج توصيات كل جلسة وملخص التوصيات الجماعي في الجدول أو الصفحة المركزية نفسها، ولا يُنشأ ملف ملخص توصيات مستقل في كل مرة. تُنشأ وثيقة منفصلة فقط إذا طلب المالك مخرجًا مستقلًا، مع بقاء الجدول المركزي مرجع الآراء والقرار.

كل صفحة تقرير تذكر المعرّف، النوع، التاريخ، الحالة، الجلسات المشاركة، المراجع، ومعرّفات التقارير المرتبطة. لا تكرر التقرير داخل ملخص التوصيات؛ يكتفي الملخص بالتوصيات ومصدرها.

## دورة العمل

1. يحدد المالك السؤال والنطاق، ثم يفتح المنسق موضوعًا ومعرّفًا ثابتًا.
2. يرسل المنسق السؤال نفسه أو ما يلائم دور كل جلسة، ثم يسجل رأيها وتصويتها في عمودها بالجدول المركزي مع السبب ومصدره.
3. يسجل المنسق التقييم والتوصيات الجماعية وملخصها في الصفحة المركزية؛ لا ينشئ ملف ملخص توصيات منفصلًا افتراضيًا.
4. يسجل التصويت فقط إذا طُلب، مع الأصوات والامتناع وعدم الرد كما حدثت.
5. يسجل قرار المالك منفصلًا، وتحدث صفحة الفهرس بالحالة والروابط.
