مراجعة جلسة «تنسيق إنتاج SVG» لجرد المهارات

معرّف الموضوع: SKILLS-REVIEW-001 | التاريخ: 28 أكتوبر 2026 | نوع المستند: رأي جلسة مستقل | الحالة: توصية غير معتمدة

حدود الرأي: التصنيف أدناه يقيس الصلة بدور تنسيق عقد SVG والتحقق والتصدير فقط. «أرشفة مقترحة» لا تعني أن المهارة غير نافعة في مشاريع أخرى أو أن على المالك حذفها. لم تُغيّر الجلسة إعدادات أو تثبيتات. الجرد المرجعي المحلي يضم 130 ملفًا و127 اسمًا فريدًا؛ الوجود المحلي لا يثبت إتاحة كل مهارة في كل سطح أو حساب.

تُستخدم عند الحاجة

  • exact-count-and-zero-tables — تدقيق أعداد المسارات والنقاط وصفر الفقد أو الزيادة.
  • focused-testing — اختيار تحقق مركز بعد تغيير التصدير أو العقد.
  • minimal-code-edit — تغيير محدود في SVG بعد إثبات الحاجة وموافقة مالك الملفات.
  • targeted-debugging — تشخيص عطل محدد في التصدير أو الاستيراد.
  • review-agent — مراجعة مستقلة لتغيير أو diff محدد.
  • build-report — إعداد تقرير HTML موثق عند الحاجة لتسليم مرجعي.
  • openai-docs — أسئلة Codex أو OpenAI المتغيرة، لا توثيق SVG العام.
  • playwright — أتمتة متصفح عند الحاجة والسماح؛ لا يحل محل فحص التطبيق أو الجهاز.
  • pdf — عند إنشاء أو فحص PDF، وليس لمسار SVG المعتاد.
  • validate-data — تدقيق منهجية وأرقام تقرير قياس كمي.
  • accessibility, fixing-accessibility, web-design-guidelines — عند تغيير واجهة التصدير أو المعاينة؛ متداخلة جزئيًا.
  • frontend-design, ui-ux-pro-max — عند تصميم أو تعديل واجهة؛ متداخلتان بقوة ولا يلزم استدعاؤهما معًا افتراضيًا.

استعداد؛ لا تُستدعى افتراضيًا
