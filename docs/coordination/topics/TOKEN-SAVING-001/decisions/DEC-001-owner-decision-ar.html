قرار المالك كما ورد

اعتماد تجربة قصيرة: بطاقة تسليم، مالك واحد لكل نطاق، سجل قرارات، إبقاء فحوص الجودة، وقياس محلي لفترة محددة.

طريقة التطبيق خلال التجربة

  1. تستخدم الجلسات بطاقة التسليم المحددة في دليل التنسيق: الهدف، الملفات أو العينة، القرارات، دليل القياس، العائق، والخطوة التالية.
  2. يعلن مالك واحد لكل نطاق وملف؛ يراجع الآخر سؤال قبول محددًا بدل إعادة استكشاف العمل كاملًا.
  3. تسجل القرارات والعقود والإصدارات في مرجع المشروع، وتربط تقارير الجلسات به.
  4. تبقى اختبارات القبول وفحوص CI ومراجعات الجودة المطلوبة نافذة؛ التوفير يكون في تكرار السياق والسرد.
  5. يسجل قياس التوكنز محليًا لكل جلسة، مع فترة البداية والنهاية والنموذج والإعدادات، دون تداول JSON الخام أو نسبة الحصة الأسبوعية المشتركة إلى جلسة.

نافذة التجربة

اعتمد المالك مدة أسبوع واحد، من 28 أكتوبر إلى 4 نوفمبر 2026. يعرض المنسق النتائج بعد انتهاء النافذة أو عند توجيه المالك بإنهاء التجربة مبكرًا.

مقاييس المراجعة

  • اكتمال بطاقة التسليم في كل عملية تسليم خلال الفترة.
  • عدد مرات إعادة استكشاف الملفات نفسها دون تغير في المدخلات أو ظهور تعارض.
  • التزام جميع التغييرات بفحوص القبول وCI المطلوبة.
  • فروق عداد التوكنز لكل جلسة وفترة مقارنة، مع توضيح اختلاف النموذج والإعدادات؛ لا تعلن نسبة توفير قبل توفر خط أساس قابل للمقارنة.

حدود التفويض

هذا القرار يعتمد أسلوب عمل وتوثيق وقياس فقط. لا يجيز تعديل إعدادات Codex أو كود المسجل أو خوارزميات المسارات أو تنفيذ اتصال/تشغيل للطابعة. لا يوجد تصويت؛ القرار صدر من مالك المشروع.

مراجعة نهاية الفترة
