المصدررسالة الجلسة في نقاش توفير التوكنز؛ مراجعة استشارية فقط.

التوصيات التي قدمتها الجلسة

  1. بطاقة تسليم قصيرة لكل جلسة: الهدف، الملفات أو العينة، القرار المعتمد، دليل القياس، العائق والخطوة التالية؛ رابط التقرير بدل نسخ سجل المحادثة.
  2. مالك واحد لكل نطاق وملفات؛ استكشاف واحد، ومراجع يجيب عن سؤال قبول محدد بدل إعادة فحص العمل كله.
  3. مرجع موحد للقرارات والعقد والإصدارات؛ إعادة التحقق فقط عند تغير الكود أو العينة أو إصدار البرنامج أو ظهور تعارض.
  4. إعادة استخدام الفحوص المناسبة مع إبقاء بوابات CI والقبول؛ الاختصار في السرد والتكرار لا الأدلة أو شروط القبول.
  5. قياس محلي بنافذة بداية ونهاية، ونموذج/جهد تفكير ثابت قدر الإمكان، بلا استدعاءات نموذج للقياس. لا تنسب الحصة الأسبوعية لجلسة ولا تحول العداد إلى نسبة الحصة.

ملاحظات على الهيكلة

أوصت الجلسة بفهرس HTML مركزي، وتقارير تقييم لكل منها توصيات مرتبطة. توصي بتقليل التكرار؛ استجابةً لطلب المالك، جهز المنسق ملخص التوصيات كملف منفصل ذي معرّف واضح ورابط متبادل، مع عدم تكرار متن التقييم فيه. دليل القياس الحالي يبقى في موقعه ولا ينقل.
