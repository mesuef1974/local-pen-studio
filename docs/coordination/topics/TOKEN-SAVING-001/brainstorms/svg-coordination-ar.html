المقترحات التي قدمتها الجلسة

  1. استخدام بطاقة تسليم موجزة وتقرير/عينة برابط بدل نسخ المحتوى كاملًا.
  2. تسليم مرحلي واضح بين المسارات، بحث الطابعة، وتحقق SVG/CAM.
  3. تمرير أقل سياق كافٍ: المهمة وحدود الملكية وملف أو عينة محددة.
  4. إعادة استعمال النتائج المؤكدة وعدم تكرار التحقق إلا عند تغير المدخلات أو الإصدارات.
  5. اختيار النموذج والتفكير والمهارات حسب صعوبة المهمة؛ لا تحمل أدوات غير لازمة لمراجعة نصية.
  6. البحث للمعلومات المتغيرة أو غير المؤكدة فقط مع المصادر الأولية.
  7. قياس محلي بحسب نافذة زمنية وفروق العداد، دون نسخ JSON الخام أو نسبة الحصة الأسبوعية لمهمة.

ضوابط الجودة

عدم اختصار تعريف الوحدات والعقد ومعايير قبول SVG أو حذف أدلة الاختبار؛ وفرق التوكنز لا يقيس جودة الهندسة. لم تعدل الجلسة الكود ولم تشغّل اختبارات.
