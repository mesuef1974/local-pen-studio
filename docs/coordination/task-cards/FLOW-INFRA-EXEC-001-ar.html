أمر المالك والنتيجة المطلوبة

تنفيذ قاعدة بيانات احترافية محلية تستبدل ملفات JSON المشتقة من مسجل التوكنز ولوحته بجداول SQLite، وتجعل اللوحة تقرأ من API محلية. أضف مخططًا قابلًا للترقية لسجل البطاقات والآراء وقرارات المالك والتسليمات. احفظ البيانات محليًا ولا ترسلها إلى خدمة خارجية.

تظل سجلات Codex الخام بصيغة JSONL مصدر الإدخال للقراءة فقط؛ لا تُحفظ نصوص المحادثات أو محتوى الأدوات. لا يشمل التكليف إنشاء PostgreSQL أو فتح منفذ شبكي أو دمجًا أو نشرًا.

النطاق وآلية العمل

المرحلةالعملمعيار الإنجاز
1 · تثبيت المصدر☑ اكتمل محليًا ثُبت مصدر scripts/usage_monitor/ في الشيفرة؛ ملفات البيانات وقاعدة SQLite مستثناة.ستُراجع الملفات المتعقبة في الـcommit، دون إضافة بيانات المستخدم.
2 · تصميم المخطط☑ اكتمل مخطط v4 بحالة حالية منفصلة عن سجل أحداث append-only، وقواميس حالة/سبب مرقمة، وإسناد وآراء وقرارات مالك وتسليمات وفحوص وتعثرات، مع فصل جداول القياس.تحولات الحالة تُسجل في الحدث والحالة الحالية ضمن معاملة واحدة؛ ربط القياس بالبطاقة صريح؛ سجل الحدث لا يقبل التعديل أو الحذف.
3 · ترحيل محافظ☑ اكتمل فعليًا استورد 13 ملف قياس قديمًا و4,971 عينة و66 مؤشر قراءة؛ وتستمر العينات الجديدة في الوصول للجدول. ملفات JSON بقيت كما هي.استيراد مرة واحدة داخل معاملة؛ فُحصت سلامة القاعدة وعدم حذف بيانات المصدر.
4 · الكاتب المحلي☑ يعمل المسجل يكتب إلى SQLite كل دقيقة، ومؤشرات المصدر تحفظ مع العينات في المعاملة.اجتاز اختبار كاتبين متزامنين دون تكرار، واختبار استكمال سطر JSONL غير المكتمل.
5 · API واللوحة☑ يعمل endpoint /api/dashboard على 127.0.0.1:8769؛ اللوحة تقرأ SQLite ولا تعتمد لقطة JSON دائمة.أعادت API 13 جلسة والقراءة الأسبوعية؛ الخادم مربوط بعنوان loopback.
6 · النسخ الاحتياطي☑ تم أداة SQLite Backup API أنشأت نسخة محلية وفحصت integrity_check.ملف النسخة خارج المستودع؛ لا نسخ يدويًا لملف WAL حي.
7 · التحقق وGit☑ اكتمل 9 اختبارات ناجحة، فحوص صياغة Python/JavaScript/PowerShell ناجحة، ومخطط قاعدة الاستخدام v4 سليم (integrity_check=ok). دُفع commit التنفيذ وتطابق HEAD المحلي مع remote.الفرع codex/workflow-infrastructure-brainstorm-001 · commit التنفيذ 05268dd2d050caebe4c14aa2335436688d2375df.

القيود والضوابط

  • عدم حذف أو إعادة تسمية أي ملف بيانات محلي قائم. يحتفظ بمخرجات JSON القديمة كنسخة رجوع حتى اعتماد المالك حذفها لاحقًا.
  • نسخ قاعدة البيانات عبر SQLite Backup API أو نسخة متسقة، لا عبر نسخ ملف حي عند استخدام WAL.
  • عدم إضافة اعتماديات خارجية إن كانت مكتبة Python القياسية تفي بالغرض؛ لا تثبيت حزم أو خدمات.
  • عزل القياسات عن محتوى المحادثات؛ وعدم ربط قياس جلسة ببطاقة لمجرد تقارب التوقيت.
  • عدم تشغيل ترحيل إنتاجي أو تغيير المهمة المجدولة على نسخة المستخدم قبل مراجعة نتائج النسخة التجريبية في مجلد مؤقت.
  • إذا تعذر تحقيق شرط، يُسجل السبب والدليل في البطاقة وتبقى المهمة مفتوحة.
