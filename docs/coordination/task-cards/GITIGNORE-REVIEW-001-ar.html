المطلوب

راجع تعديل .gitignore في شجرة العمل المنقولة، وطابق محتويات scripts/usage_monitor/ المحلية المتجاهلة مع النسخة الموجودة في origin/main. صنّف كل ملف إلى مصدر أو توثيق أو اختبار أو migration أو runtime/generated، ثم ارفع توصية ضيقة للمالك قبل أي تعديل.

المؤكد من الفحص الحالي

الدليلالنتيجة المرصودة
ملف التجاهل في شجرة العمليحتوي /*، ثم !/scripts/، ثم قاعدة محلية غير ملتزمة /scripts/usage_monitor/ في السطر 139؛ وgit diff -- .gitignore يثبت إضافتها. تغييرات الـallow-list الأخرى في الجذر تشمل استثناء AGENTS/أرشيف وإزالة استثناءات HTML وPNG وJSON الجذرية.
قرار Gitgit check-ignore -v --no-index يعزو تجاهل README وملفات مصدر وdashboard-data.json إلى السطر 139؛ ويظهر المجلد !! في git status --ignored.
مقارنة المجلد المحليجُردت 20 ملفًا: 14 ملفًا موجودة في origin/main، منها 13 مطابقة بايتًا ببايت، وdashboard.html مختلف. المحلي فقط: build_dashboard_data.py، وdashboard-data.json بحجم 945,747 بايت، وأربعة ملفات __pycache__. لم يُقرأ JSON.
شجرة mainorigin/main عند 72f559d يتتبع ملفات المصدر والاختبارات والوثائق وmigrations في scripts/usage_monitor/؛ لا توجد به قاعدة المجلد الواسعة. README يحدد SQLite والنسخ الاحتياطية خارج Git في %USERPROFILE%\.codex\usage-logs.
شجرة الفرعcodex/webgpu-adaptive-validation عند b76a83c مقابل origin عند commit نفسه؛ HEAD أقدم من main، لذلك لا يحتوي هذه الملفات. لا يفسر ignore وحده فرق الشجرتين.

فصل الدليل عن التفسير: هذه نتائج قراءة Git والملفات الحالية؛ لا تثبت من أنشأ قاعدة التجاهل المحلية أو محتوياتها المتجاهلة.

الاستنتاج وما يحتاج حسمًا

  • قاعدة التجاهل الواسعة تخفي نسخة محلية تضم مصادر ووثائق واختبارات وmigrations؛ 13 نسخة مطابقة لمصدر main، وdashboard.html مختلف. الملفات المحلية الإضافية هي أداة توليد مصدر، وJSON مولد، وأربعة ملفات bytecode مولدة.
  • غياب الملفات عن HEAD الفرع ناتج أيضًا عن قدم الفرع؛ فرق main/branch ليس أثر ignore وحده.
  • ملكية تعديل .gitignore، وdashboard.html المختلف، وbuild_dashboard_data.py، وdashboard-data.json وملفات bytecode غير محسومة.
  • التوصية الاستشارية: لا ترفع المجلد كله. بعد قرار المالك، تُتاح ملفات المصدر والوثائق والاختبارات وmigrations، وتُستثنى مخرجات محددة مثل JSON المولد و__pycache__ وأي DB/WAL محلي؛ وتُحسم الملفات المختلفة منفصلًا.

آلية المراجعة ومعايير الإقفال

  1. توثيق git status وفرق .gitignore ونتيجة قواعد check-ignore دون تغييرها.
  2. جرد أسماء الملفات المتجاهلة ومقارنة النسخة المحلية مع مسارات origin/main؛ لا تنسخ المحتوى أو تطبّق مزامنة تلقائية.
  3. تصنيف الملفات إلى مصدر/توثيق/اختبار/migration أو بيانات runtime/generated، مع تحديد الملفات المتطابقة والمختلفة والجديدة.
  4. تحديد مالك التعديل المحلي؛ وعند تعذر ذلك يبقى «غير محسوم» ولا يُنسب التغيير لجلسة بالتخمين.
  5. رفع توصية للمالك بشأن قاعدة التجاهل والملفات التي ينبغي إبقاؤها خارج Git. أي تعديل أو إضافة أو حذف أو commit/push يحتاج تكليفًا منفصلًا بعد العزل.
معيار الإنجاز: تقرير أدلة يبين الفرق بين HEAD الفرع وmain، قائمة الملفات وتصنيفها وملكيتها، المخاطر، وأقل تغيير موصى به؛ مع إبقاء قرار المالك منفصلًا.

حدود البطاقة

  • هذه البطاقة للتنسيق والتدقيق فقط؛ لا تغيّر .gitignore ولا تضف الملفات المتجاهلة ولا تحذفها.
  • لا تستخدم git add -f على المجلد كاملًا، ولا تنفذ reset أو تنظيفًا، ولا تخلط ملفات جلسات أخرى.
  • لا يُدفع أي تغيير من شجرة العمل الحالية قبل عزل ملكيته؛ حالة Git فيها ملفات أخرى غير ملتزمة.
